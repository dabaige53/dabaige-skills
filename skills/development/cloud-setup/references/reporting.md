# 回复模板

先完成当前授权内能自主完成的配置，再回复。每个子项目用短句说明：

**子项目名称**
- 在哪运行，怎么启动。
- 哪台机器必须安装或配置什么；说明已完成的内容。
- 数据、任务进度和结果放在哪里，各端怎么使用。
- 仍未完成的具体问题。

最后仅在需要用户补充时列出“需要你补充”：

- 提供邮件服务密钥：保存到项目凭据入口的 `EMAIL_API_KEY`，用于发送通知。
- 授予存储访问权限：给运行账号开通结果目录的读写权限。
- 登录采集软件：在运行采集程序的电脑上完成登录。

以上是写法示例，只列实际缺少的项，写清用途和提供位置。能自行查到或配置的内容由 Agent 完成。密钥通过项目凭据入口提供，回复只写来源或变量名。没有需要用户处理的事项时省略该清单。

使用具体名称和动作，不用“节点、产物、配置源”等术语。没查清写“还没确认”；旧项目尚未迁完或尚未关闭的服务列为未完成事项。
