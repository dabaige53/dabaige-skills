# 问题定位

从实际失败环节选择下一步：

| 现象 | 查看什么 |
| --- | --- |
| 无法启动 | 原始错误、退出状态、依赖、运行身份和加载的配置 |
| 服务存活但任务未完成 | 同一任务的接收、排队、执行、保存记录，找到最后进度 |
| 定时任务未执行 | 时区、周期、启停状态、最近触发和执行记录 |
| 一端正常，另一端失败 | 两端真实入口、参数、配置来源、权限及依赖访问方向 |
| 状态或结果不一致 | 同一任务对应的数据库、业务范围、缓存和产物存储 |
| 有产物但无法使用 | 本次运行的输出内容、完整性、上传状态和使用者权限 |
| 运行缓慢 | 各步骤耗时、排队、资源占用、限流和重试记录 |

先修正最有依据的原因，再观察原问题。节点不可访问时标明未检查；配置无效且可安全恢复时撤回本次修改。
