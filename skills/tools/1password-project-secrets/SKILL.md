# 项目凭据与运行

## 授权优先级

先确认当前任务的授权范围和项目已有的认证方式，再按以下顺序选择入口。任一入口能完成当前操作，就直接使用。

1. **产品插件或连接器**。核对已连接的账号、权限和操作能力。未连接且需要该入口时，优先使用产品提供的连接流程。
2. **项目现有认证**。插件或连接器覆盖不了当前操作，或本地进程仍需凭据时，沿用项目已配置的认证方式和原运行入口。
3. **本机 1Password Service Account**。项目已采用本机 1Password 管理所需凭据，或用户明确要求配置或迁移到该方式时，才使用本机入口。认证失败时，按当前权限排查。扩权、改用 1Password 桌面授权或其他认证方式、迁移凭据均需用户授权。

## 通过 1Password 运行项目

1. 读取项目规则和原运行命令。帮助、测试及离线检查在无需凭据时直接运行。项目已验证本机映射且命令需要凭据时，用 `project-run` 包装原命令。

   ```sh
   project-run <项目目录名> -- <原运行命令>
   ```

2. 按当前授权验证实际入口，只输出配置状态。注入成功与业务运行成功分开报告；缺值或失败先修复，不生成替代密钥。
3. 交付只给用户可执行的项目命令、验证结果和仍阻塞运行的事项。
