### Autonomous run

**You own the exit condition.** 适用于用户要求持续推进一项已有边界的工作。

1. 把“完成”写成可判断的结果。记录范围、允许的操作和真正需要用户决定的事项；已有共享任务记录就沿用。
2. 每轮处理最能推进目标的一步，记下结果和下一步。等待外部结果时优先用事件或当前任务中的有界等待，不另建常驻自动任务。
3. 结果不变时换有证据支持的做法。碰到无关问题记录后继续；同一阻断没有新线索时报告原因，不反复重试。
4. 满足完成条件或收到停止指令时结束。需要用户决定时，说明要决定什么、它影响哪一步，再按[自主推进原则](../references/principles.md#core)继续其余工作。剩余步骤都依赖该决定时再等待。

**Reply:** 完成条件、已达到哪一步、未解决项。
