### Eval

**You own the experiment design. Plan, blind, run, synthesize.**

1. 先定要比较的变化，写下三至六项可观察标准，只给评判方。准备相同任务、输入和权限，候选方看到自然任务描述。
2. 在隔离位置产出结果，不在候选材料中暴露评分项、模型或其他候选。
3. 把匿名结果交给同一评判方，使用同一把尺子。主 Agent 阅读实际产物；若关心工具是否被使用，用允许读取的记录判断，不靠自述。
4. 对照结论与证据，指出样本太少、环境不同或标准含糊的影响。用户未要求评测时，不附带执行此流程。

**Reply:** 比较项、标准、结果差异、推荐及限制。
