# Build

1. 核查现有入口、采集器、校验器、调度定义和状态机制。按“直接复用 → 参数化或局部修复 → 新增”选择实现。
2. 按默认交付结构落地；固化稳定规则，按实现契约编写或复用脚本与 AI 步骤。
3. 为已有调度器编写轻量运行入口，接入必要事件记录。记录运行时配置版本，输出失败分类与可恢复断点；明确实际预算控制组件。
4. 进入 validate，验证本次新增或修改的路径。

## 默认交付结构

新建工作流时，默认在项目 `docs/workflow/<流程名>/` 落地；已有工作流沿用其实际目录及配置。

```text
docs/workflow/<流程名>/
├── README.md           # 设计摘要、使用方式与运行依赖
├── workflow.yaml       # 任务、依赖、条件、执行顺序
├── <流程名>.workflow.md # 面向人和 Agent 的流程说明
├── prompt.md           # AI 自动化任务的轻量入口
├── scripts/
│   ├── preflight.py    # 环境检查
│   ├── collect.py      # 确定性信息采集
│   ├── execute.py      # 确定性操作
│   └── lint.py         # 规则与结果验证
├── state/              # 执行状态与断点
└── logs/               # 执行与故障记录
```

- 默认交付 `README.md`、`workflow.yaml`、`<流程名>.workflow.md`、`prompt.md` 四类交付文件。若沿用项目原生配置，README 指向真实定义，避免维护第二份工作流事实源；无需 AI 的流程可省略 prompt。
- `workflow.yaml` 记录触发器、步骤 ID、执行主体、紧前依赖、分支、输入输出、完成条件、失败出口及实际资源路径。采用通用描述时遵循 contract；目标环境无 YAML 支持时复用已有格式（如 JSON），不强制新增依赖。
- 流程说明固定使用 `<workflow-id>.workflow.md` 命名；例如 ID 为 `daily-sales` 时，文件为 `daily-sales.workflow.md`。新流程的目录名默认与 ID 一致；已有 ID 不适合作文件名时，采用明确映射的安全名称，不擅自修改实际 ID。文件位置可按项目约定配置。
- 从实际工作流定义生成或更新流程说明，参考 [sample-review.workflow.md](../assets/sample-review.workflow.md)。记录触发、步骤 ID、执行主体、输入输出、紧前/紧后、条件分支、异常出口和完成标准；命令与脚本链接指向真实入口。README 保留摘要和使用方式，链接流程说明；`workflow.yaml` 或平台原生定义仍为唯一执行事实源。修改流程时同步更新说明，实际执行轨迹以运行事件为准。
- `scripts/` 下的四类脚本为默认职责与命名示例，按需创建；已有脚本或 CLI 可直接引用，不复制、不创建空壳。
- 按实际需要配置 `state/` 和 `logs/`；运行数据和凭据保存在项目外或平台存储中。
- 构建完成时返回实际文件树和复用/外部资源引用，标明与默认结构的差异。禁止仅返回计划树作为落地结果。

## 实现契约

- 参数传入路径、输入范围、工作流/运行/步骤 ID；明确相对路径基准。
- 约定结构化输入输出、退出码和错误分类；通过参数数组调用命令。
- 实现方案要求的有限超时、重试、幂等、状态提交和并发控制，优先复用执行器已有能力。
- 采集设时间、文件、字节或记录上限。缓存注明输入范围、新鲜度、失效条件与刷新入口。
- AI 接收必要证据，输出固定字段；证据不足时返回可识别状态。
- 接口或业务规则变化时更新版本与对应验证；保留兼容调用方式。运行状态与凭据不得进入版本库；依赖、解释器、连接器能力及实际入口应能在目标环境复现。
- 构建与上线分离。先保存原调度定义、入口版本和恢复方法；验证后按授权替换，避免新旧任务重叠。回滚仅恢复定义与版本，不自动撤销已发生的外部副作用；先对账。

## 轻量运行入口

入口仅包含配置位置、本轮输入或断点、既有脚本/工具调用、完成判定、失败出口和简短返回格式。正常定时执行加载这个入口；工作流改造或异常调查才加载 loop-agent。

记录工作流、run、step、attempt、实际执行者、时间、结果与产物引用。采用通用配置或事件格式时读取 contract；平台已有格式可直接保留。状态存储尚未确定时，先解决跨轮恢复所需的持久化位置。

**结束条件**：实现文件及入口已落地，复用关系清楚，受影响路径的验证已有结果；失败或未验证项有具体恢复动作。按公共约定返回变更树与摘要。
