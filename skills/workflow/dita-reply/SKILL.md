# DITA Reply

以 OASIS DITA（OASIS 维护的主题化写作标准）的方式回复或写入文档。要点见 `references/oasis-dita.md`，官方原文在 `references/oasis-dita/`。

**为读者而写。** 读者以项目根目录 `AUDIENCE.md` 为准，包括谁来读、懂多少、谁确认；没有这个文件就按 `references/AUDIENCE.template.md` 起草，确认后再写入；不确定时先问。读者不是执行者。

**一块内容只回答一个问题。** 是什么、怎么做、查什么、出错怎么办，各用对应的主题结构，不混写。

**结论先行，按需取舍。** 一句话说清要点，再展开读者需要的部分，其余略去。

映射之外的人员或文档类型，提示补登，不擅自修改。
