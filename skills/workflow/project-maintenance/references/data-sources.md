# 数据源调整

仅在用户明确要求切换来源或迁移相关功能时使用；配置文档时只记录现行规则。

## 确认来源与加工过程

逐项确认业务用途、当前来源、目标来源、加工入口、字段与粒度、消费模块及验证方式。优先读取现有适配器、正式元数据、迁移记录和原实现。

只修改已确认映射的配置和读取代码。保留用户指定的例外和未迁移来源；映射不明时报告具体缺口，不新增数据库对象或用相似数据代替。目标读取失败时明确报告，不擅自回退旧来源或返回空数据假装成功。

找不到旧表名时，继续搜索消费函数、指标字段、聚合 SQL 和原加工代码，确认结果是否由源数据派生。迁入功能时检查模块、导入路径、SQL、模板及依赖是否完整。

## 保持统计口径

按实际业务核对日期边界、粒度、去重键、连接基数、空值、类型转换、单位、排序及相关边界情况。保留原有指标定义。

在保持结果的前提下下推过滤和必要聚合。共享连接或缓存前确认线程安全、事务边界及来源版本。

## 完成条件

受影响输入均有已确认来源或明确缺口。对照变更前后的行数、关键汇总和必要边界样本；映射正确不代表加工结果等价。分别报告离线等价检查、真实只读连通和完整业务运行的结果，不相互替代。问题沿用项目现有记录入口，不自动新建迁移报告或错误文件。
